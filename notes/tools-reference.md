# Tools Reference

Quick notes on tools used during investigations.

| Tool | Purpose | Notes |
|---|---|---|
| VirusTotal | File/URL/IP reputation | Check detection ratio + community comments |
| Wireshark | Packet capture analysis | Filter by `ip.addr`, `http`, `dns` |
| AbuseIPDB | IP reputation/abuse reports | Good for confirming known-bad IPs |
| LetsDefend SIEM | Log correlation & alert triage | Main simulator environment |
